# SubShelf

Трекер подписок и пробных периодов для Android и iPhone. Показывает, какие подписки активны, когда и сколько спишут, и напоминает заранее, чтобы пробный период не стал платным незаметно.

Данные хранятся только на телефоне: без сервера, аккаунта, рекламы и слежки. Интернет нужен только для поиска иконок и покупки Pro.

## Возможности

**Бесплатно**

- **До 5 подписок.** Пробные и активные отдельно, у каждой цена, валюта, период, дата списания и категория.
- **Напоминания.** Уведомление за выбранное число дней до списания и в сам день, в выбранное время.
- **Сайт и иконка сами.** Вставьте ссылку (`https://tembo.io/pricing`) или напишите название («Obsidian», «Кинопоиск»): приложение найдёт сайт и иконку. Сначала встроенный каталог (100+ сервисов) без интернета, потом официальный сайт из Wikidata и проверка адресов `.com`, `.io`, `.ai`… Если вариантов несколько, их видно под названием. Поиск можно выключить.
- **Отменить на сайте.** В карточке подписки кнопка ведёт прямо на страницу отмены или управления (Netflix, Spotify, YouTube, Claude, Adobe и другие) или на сайт сервиса.
- **Пробное закончилось.** Если дата пробного прошла, приложение спросит: подписка стала платной или вы её отменили, и разложит её куда нужно. Нажатие на напоминание открывает нужную подписку.
- **История.** Отменённые подписки уходят в историю с датой отмены, их можно вернуть. Видно, сколько вы экономите.
- **Резервная копия.** Экспорт в JSON и восстановление из файла.

**SubShelf Pro**

- Сколько угодно подписок.
- **Обзор:** прогноз расходов на 12 месяцев, календарь списаний, расходы по категориям, самые дорогие подписки.
- Экспорт в CSV для Excel, Numbers и Google Sheets.

Pro продаётся подпиской (месяц или год с бесплатной неделей) или навсегда. В Google Play и App Store оплата через магазин (RevenueCat), в APK с GitHub по ключу активации. Кто пользовался приложением до появления Pro, получает его бесплатно.

## Дизайн

Один светлый стиль без настроек: тёплая бумажная палитра и тонкие линии, как у [Hoplite](https://hoplite.sh), сгруппированные списки и шторки, как в приложениях Apple. Шрифты Geist и Geist Mono, один акцент: сигнальный красный `#ff3616`. Ни одна подпись не переносится на вторую строку на любом телефоне.

## Установка

- **Android, APK:** откройте [последний релиз](../../releases/latest) на телефоне, скачайте `SubShelf-*.apk` и установите. Подходит и для Huawei без сервисов Google.
- **Google Play и App Store:** после публикации, см. [docs/PUBLISHING.md](docs/PUBLISHING.md).

Новые версии APK ставятся поверх старых, данные сохраняются.

## Разработка

```bash
npm install
npm run dev          # веб-версия в браузере (покупка Pro там демонстрационная)
npm run check        # типы, тесты, форматирование
npm run android      # сборка и синхронизация с android/
npm run ios          # сборка и синхронизация с ios/ (собирать на Mac или в GitHub Actions)
npm run license -- --help   # ключи активации для APK
```

Стек: Vite, React 19, Tailwind CSS 4, Capacitor 8 (Preferences, Local Notifications, Share, Status Bar, Haptics, Browser, Device), RevenueCat.

Канал сборки задаёт `VITE_STORE`: `play`, `direct` (APK) для Android; iOS всегда App Store; браузер всегда демо. Остальные переменные (ключи RevenueCat, публичный ключ лицензий, ссылки) описаны в [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Сборки

- **CI:** каждая ветка и pull request: проверки, отладочная сборка Android и сборка iOS для симулятора.
- **Android release:** каждый пуш в `main`: подписанные APK (для GitHub) и AAB (для Google Play), релиз `v1.0.<номер>`.
- **iOS release:** запускается вручную в Actions и загружает сборку в TestFlight. Mac не нужен.
