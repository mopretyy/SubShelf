# Графика для магазинов

Всё готово к загрузке: размеры и формат подходят под требования, прозрачности в картинках нет.

| Папка / файл                             | Куда                                                       | Размер    |
| ---------------------------------------- | ---------------------------------------------------------- | --------- |
| `screenshots/appstore-6.9/ru`, `/en`     | App Store Connect → скриншоты iPhone 6.9″                  | 1320×2868 |
| `screenshots/appstore-ipad-13/ru`, `/en` | App Store Connect → скриншоты iPad 13″                     | 2064×2752 |
| `screenshots/play-phone/ru`, `/en`       | Play Console → Основная страница → Скриншоты телефона      | 1080×2160 |
| `feature-graphic/feature-ru.png`         | Play Console → Обложка (feature graphic), русская страница | 1024×500  |
| `feature-graphic/feature-en.png`         | то же для английской страницы                              | 1024×500  |
| `icon-512.png`                           | Play Console → Значок приложения                           | 512×512   |

Значок для App Store берётся из сборки (`ios/App/App/Assets.xcassets`), отдельно его загружать не нужно.

Порядок скриншотов: 01 список подписок, 02 напоминания, 03 прогноз на год, 04 календарь, 05 профиль и экономия, 06 приватность.

Для проверки покупок в App Store (скриншот экрана Pro у каждого товара) снимите экран Pro в сборке из TestFlight: там настоящие цены из магазина.
